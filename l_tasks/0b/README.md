# Задача 0б

Сборка и пример запуска:

```sh
make
./word_count input.txt output.csv
```

Программа читает строки с помощью `std::getline` и сохраняет их в
`std::list<std::string>`. Частоты накапливаются в
`std::map<std::string, int>`, затем пары переносятся в `std::list` и
сортируются по убыванию частоты.

Разделителем считается любой символ, для которого `std::isalnum` возвращает
ноль. Регистр сохраняется, поэтому `Word` и `word` считаются разными словами.
Доля вычисляется от общего количества найденных слов. В третьей колонке
записывается числовой процент без символа `%`.
